1. Project Overview
GRASP is a full-stack cybersecurity platform built from scratch as a dynamic website. It detects anomalies in medical supply chain networks in real time using 15 parallel AI agents, a GPU-accelerated Graph Neural Network, and an LLM-powered explainability engine. The entire system is exposed through a live React dashboard with real-time graph visualization.

5. Frontend Pages — Dynamic Website Design

5.1 Real-time data flow to UI
The frontend uses a single persistent WebSocket connection to receive live updates. Zustand manages global state so any component can react to new events without prop drilling. Here is the exact flow when a new event arrives:

Backend detects new event → runs 15-agent parallel swarm (~15ms)
Decision engine outputs risk score → WebSocket pushes message to all clients
useWebSocket.js hook receives message → updates Zustand graphStore
All subscribed components re-render automatically — graph nodes recolor, log panel appends, agent bars update
If anomaly: Safe Box updates, anomaly counter increments, alert banner shows

7.2 Key papers — read in this order
Hamilton et al. (2017) — GraphSAGE. Your GCN model is based on this.
Zugner et al. (2018) — Mettack adversarial attacks on GNNs. Your poisoning test.
Ying et al. (2019) — GNNExplainer. Your explainability module.
Sommer & Paxson (2010) — ML for network intrusion detection. Background for your CPU agents.
Milajerdi et al. (2019) — HOLMES: APT detection via provenance graphs. Your temporal agent.
Alsaheel et al. (2021) — ATLAS: sequence-based attack investigation. Lateral movement agent.
Continella et al. (2016) — ShieldFS: ransomware detection. Your ransomware agent.
Park et al. (2023) — Generative Agents. Agentic AI patterns for your swarm design.

9. Setup Commands — Run in This Order
9.1 Backend setup
# 1. Create virtual environment
python -m venv venv && source venv/bin/activate

# 2. Install backend dependencies
pip install fastapi uvicorn[standard] torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install torch-geometric networkx scikit-learn deeprobust pandas numpy scipy
pip install anthropic openai python-dotenv

# 3. Verify GPU
python -c "import torch; print('CUDA:', torch.cuda.is_available(), '| GPU:', torch.cuda.get_device_name(0))"

# 4. Run backend
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

9.2 Frontend setup
# 1. Create React app with Vite
npm create vite@latest frontend -- --template react
cd frontend

# 2. Install dependencies
npm install tailwindcss @tailwindcss/vite cytoscape recharts chart.js
npm install zustand react-router-dom axios

# 3. Run dev server
npm run dev   # runs on http://localhost:5173
