
=== TABLE 1 ===
Research Title
GRASP: Graph-based Real-time Agentic Security Platform — Explainable Multi-Vector Anomaly Detection using 15-Agent Parallel Swarm with GPU-Accelerated GNN for Medical Supply Chain Cybersecurity

=== TABLE 2 ===
Component | Technology | Purpose
Backend API | Python 3.11 + FastAPI | Serves all data, runs agent swarm, handles WebSockets
AI / GNN | PyTorch + PyTorch Geometric (CUDA) | GCN on RTX 4060 — ~2ms inference
15 Parallel Agents | ThreadPoolExecutor + asyncio | All agents fire simultaneously on each event
Graph Engine | NetworkX + frozen snapshot | Supply chain graph, thread-safe parallel reads
Frontend | React 18 + TailwindCSS + Vite | Dynamic SPA — live updates, no page reloads
Graph Visualization | Cytoscape.js | Interactive supply chain network map
Charts | Recharts + Chart.js | Agent scores, risk timeline, attack statistics
Real-time Updates | WebSocket (FastAPI + React) | Live event stream pushed from backend to UI
LLM Explainer | Claude API / GPT-4 API | Plain-English anomaly reports per flagged node
Adversarial Tests | DeepRobust (CUDA) | Poisoning + evasion attack robustness tests

=== TABLE 3 ===
Stage | Module | What happens | Where
1 | Dataset Loader | Load CICIDS2017/BETH CSV or accept live event stream | backend/data/
2 | Graph Builder | Map IPs/entities to NetworkX nodes, transactions to edges | backend/services/graph_builder.py
3 | Snapshot Freeze | Deep-copy current graph — all agents read this frozen copy | backend/services/aggregator.py
4 | Parallel Dispatch | ThreadPoolExecutor dispatches all 15 agents simultaneously | backend/services/aggregator.py
5 | GPU Agents | GCN, Zero-day, Temporal/APT run on RTX 4060 via CUDA | backend/agents/gpu/
6 | CPU Agents | 12 lightweight agents run on i7 threads in parallel | backend/agents/cpu/
7 | Score Collection | Aggregator awaits all 15 scores (timeout=100ms per agent) | backend/services/aggregator.py
8 | MLP Decision | 18-input adaptive MLP on GPU outputs risk score [0,1] | backend/models/meta_classifier.py
9 | Risk Router | risk > 0.7 → Safe Box quarantine  |  else → normal flow | backend/services/decision_engine.py
10 | Explainability | GNNExplainer + LLM API generates human report for anomalies | backend/services/llm_explainer.py
11 | WebSocket Push | All results pushed live to connected React clients | backend/api/websocket.py
12 | React Dashboard | UI updates graph, agent bars, logs in real time | frontend/pages/

=== TABLE 9 ===
Total parallel detection time on your hardware
All agents fire at once. Slowest CPU agent = ~15ms (Behavior Agent). GPU agents = ~5ms max. Total = ~15-20ms per event including aggregation. The old sequential approach would take ~80ms+ on this same hardware. Your GPU drops the GCN from 80ms to 2ms alone.
