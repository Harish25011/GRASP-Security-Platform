Graph-based Real-time Agentic Security Platform

GRASP is an autonomous cybersecurity detection and incident response platform. By orchestrating a 17-agent parallel AI swarm over live network topologies, GRASP unifies statistical anomaly detection, deep sequence modeling, Bayesian log-odds consensus, and local air-gapped LLM reasoning to defend critical enterprise networks.

5-Minute Quickstart

Follow these steps to initialize the offline reasoning engine, start the backend API and packet capture workers, and boot the frontend dashboard.

Step 1: Pull Local LLM via Ollama

Bash 
# Ensure Ollama daemon is running in background
ollama pull llama3.1:8b
ollama pull phi3:mini

Step 2: Initialize Python Virtual Environment & Checkpoints

Bash 
cd backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Pre-train the 14 CPU ML agent checkpoints (~35 seconds)
python -m backend.ai_model.train_cpu_ml_agents

# Launch FastAPI ASGI Server (Requires Sudo/Admin for Scapy raw sniffing)
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Step 3: Launch React/Vite SOC Dashboard

Bash 
cd frontend
npm install
npm run dev

# Access interactive dashboard at: http://localhost:5173

REST API Reference

The backend exposes full control over packet sniffing, graph topology, live swarm analysis, and quarantine safe box state via FastAPI on port 8000.

Method Endpoint Description
POST /api/capture/start Binds Scapy sniffer to specified interface & target IP
POST /api/capture/stop Halts promiscuous packet capture worker
GET /api/capture/status Returns stream health, dropped packets, and LRU cache count
POST /api/attack Injects mock attack payload into running swarm
GET /api/analyze Executes swarm evaluation across all topology nodes
GET /api/remediation/{type} Returns structured incident analysis & shell mitigation block
GET /api/safe_box Lists all currently quarantined host endpoints
POST /api/safe_box/release/{id} Releases quarantined node back to normal routing
