# GRASP Phase 2: Ultimate System

Graph-based Real-time Agentic Security Platform — A 15-Agent Swarm with Multi-Head Attention, Scapy SNIFF, and Local Llama 3.1 LLM Explainability.

## M.Tech Thesis Defence: Live Demo Guide

This version of GRASP implements **Live Home Network Packet Sniffing** and **Offline Llama 3.1 AI Reasoning**.

### Step 1: Initialize Offline AI (Ollama)
You MUST pull the local models before the demo ensuring privacy-first execution:
```bash
# In your terminal
ollama pull llama3.1:8b
ollama pull phi3:mini
```
*Ensure Ollama is running in the background.*

### Step 2: Boot the AI Backend (Requires Admin/Sudo)
Because Scapy intercepts raw Network Interface packets, you must run the backend with Administrator permissions.
```bash
# On Windows, open PowerShell as Administrator:
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

### Step 3: Boot the React Dashboard
```bash
cd frontend
npm run dev
```
Navigate to `http://localhost:5173`.

## Running the Live Attack Demo

1. Open the **Live Threat Monitor** tab from the sidebar.
2. Under **Scapy Target Setup**, identify your target network interface (e.g., `eth0`, `Ethernet`, `wlan0`) and input a target IPv4 Address (e.g., your laptop's IP or a VM's IP).
3. Click **SNIFF**. The stream architecture monitor will light up.
4. **Trigger an Attack:** Point a secondary machine (Kali Linux) at the target IP and run Nmap, or utilize the 9 integrated **Mock Injection Buttons** natively in the React GUI to instantly force the 15-agent swarm to analyze a simulated payload.
5. The UI will flash CRITICAL, render the 30-dimensional **Multi-Head Attention Heatmap**, and the **Remediation Engine** will slide down providing instantly copyable Iptables/Firewall terminal blocks generated by Llama 3.

## Nightly Retraining (APScheduler)
Analyst Feedback logged via the dashboard is saved to `backend/data/feedback_log.csv`. Every night at 2:00 AM, the system spins up `backend/ai_model/nightly_retrain.py`, blending 30% of your manual feedback with 70% of historical vectors, retraining the 30-bar ML model via SMOTE 5-fold cross-validation!
