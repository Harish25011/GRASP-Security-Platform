System Architecture Overview
The GRASP system is designed as a hybrid multi-agent AI-based cybersecurity framework that combines rule-based detection with machine learning-driven decision making.
The system processes incoming events through a pipeline consisting of parallel agent execution, feature extraction, AI-based classification, and automated response mechanisms.
Each agent specializes in detecting a specific class of cyber threats such as brute force attacks, SQL injection, DDoS, and lateral movement. These agents operate concurrently and produce normalized risk scores.
The outputs from all agents are aggregated into a feature vector, which is then processed by a deep learning-based meta-classifier. The classifier produces a final risk score that determines the severity of the event.
Based on this risk score, the system categorizes events into four tiers: Normal, Watch, Suspicious, and Critical. Critical threats trigger immediate response actions such as isolation or blocking.
This architecture ensures real-time detection, scalability, and adaptability to evolving cyber threats.

backend/agents/cpu/*.py — update all 14 CPU agents
Each agent must now return (score, confidence). Confidence is how certain the agent is. For rule-based agents like Signature, confidence = 1.0 when it fires (regex match is certain). For statistical agents like Spike, confidence = min(1.0, z_score / 5.0). Example:
# signature_agent.py
def score(self, snapshot) -> tuple[float, float]:
match = self._check_patterns(snapshot)
if match:
return (1.0, 1.0)   # certain match
return (0.0, 0.95)      # certain no-match
# spike_agent.py
def score(self, snapshot) -> tuple[float, float]:
z = self._compute_zscore(snapshot)
risk = min(1.0, z / 3.0)
confidence = min(1.0, z / 5.0)
return (risk, confidence)

backend/models/meta_classifier.py — add attention layer
import torch, torch.nn as nn
class GRASPClassifier(nn.Module):
def __init__(self, input_dim=30):
super().__init__()
self.attn = nn.MultiheadAttention(input_dim, num_heads=5, batch_first=True)
self.fc1  = nn.Linear(input_dim, 64)
self.fc2  = nn.Linear(64, 32)
self.out  = nn.Linear(32, 1)
self.relu = nn.ReLU()
self.sig  = nn.Sigmoid()
def forward(self, x):
x = x.unsqueeze(1)                   # add seq dim
x, _ = self.attn(x, x, x)            # self-attention
x = x.squeeze(1)
x = self.relu(self.fc1(x))
x = self.relu(self.fc2(x))
return self.sig(self.out(x))

from imblearn.over_sampling import SMOTE
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import f1_score, roc_auc_score, matthews_corrcoef
import torch
def train(X, y, model, device='cuda', n_splits=5, epochs=100):
# 1. Handle class imbalance with SMOTE
sm = SMOTE(random_state=42)
X_res, y_res = sm.fit_resample(X, y)
# 2. 5-fold cross-validation
kf = StratifiedKFold(n_splits=n_splits, shuffle=True, random_state=42)
fold_metrics = []
for fold, (tr_idx, val_idx) in enumerate(kf.split(X_res, y_res)):
X_tr, X_val = X_res[tr_idx], X_res[val_idx]
y_tr, y_val = y_res[tr_idx], y_res[val_idx]
# train model on fold, record val metrics

AI Model Description
The GRASP system utilizes a Multi-Layer Perceptron (MLP) enhanced with a self-attention mechanism as its primary decision-making model.
The input to the model is a feature vector constructed from the outputs of multiple agents. This vector includes both risk scores and confidence values from each agent, resulting in a high-dimensional representation of system behavior.
The self-attention layer enables the model to dynamically weigh the importance of different agents for each event, allowing it to focus on the most relevant signals.
The architecture consists of:
Input layer (30-dimensional feature vector)
Self-attention layer for feature weighting
Two hidden layers (64 and 32 neurons)
Output layer producing a probability score
This model allows the system to capture complex, non-linear relationships between different types of cyber threats.
Part 5 — AI Architecture Upgrade: Step by Step
5.1 Training pipeline — build this first
The entire AI architecture upgrade depends on having real labeled training data. Without this, the MLP makes random decisions. Build this before anything else.
Training Pipeline
The GRASP system includes a structured training pipeline to ensure accurate and reliable threat detection.
The training process begins with the collection of labeled cybersecurity datasets such as CICIDS2017, along with simulated attack data from a controlled lab environment.
Feature vectors are generated by running all agents on each event, producing a numerical representation of system behavior.
To address class imbalance, the Synthetic Minority Over-sampling Technique (SMOTE) is applied to the dataset.
The model is trained using 5-fold cross-validation to ensure generalization and prevent overfitting. Performance is evaluated using multiple metrics, including:
F1 Score
AUC-ROC
Matthews Correlation Coefficient (MCC)
The final trained model is saved and deployed within the real-time system for inference.
This pipeline ensures that the system continuously improves and adapts to new threat patterns.
5.2 SHAP integration — build second
Explainable AI (XAI)
To ensure transparency and trust, the GRASP system incorporates explainable AI techniques using SHAP (SHapley Additive exPlanations).
SHAP values quantify the contribution of each agent to the final prediction made by the model.
Positive SHAP values indicate that an agent contributed toward classifying an event as an attack, while negative values indicate normal behavior.
These explanations are presented to analysts through the dashboard, enabling them to understand why a particular decision was made.
This capability is essential for cybersecurity systems where interpretability and accountability are critical.
